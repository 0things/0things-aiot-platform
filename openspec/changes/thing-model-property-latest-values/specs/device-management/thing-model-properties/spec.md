## Purpose

为设备详情的物模型属性页提供以产品 TSL 定义为基准的属性最后值，使用户能够在一个稳定的结构化列表中查看每个定义属性的元数据与最新上报状态。

## ADDED Requirements

### Requirement: 查询设备物模型属性最后值

系统 SHALL 提供仅针对指定设备的物模型属性最后值查询能力。响应 SHALL 按设备所属产品 TSL 的属性定义返回属性列表；每项 SHALL 包含属性名称、标识符、数据类型、单位、读写方式、最后值和最后上报时间。

#### Scenario: 返回已上报属性的最后值

- **WHEN** 用户查询存在设备，且其 TSL 中定义的属性已在时序数据中存在上报点
- **THEN** 系统返回该属性的 TSL 元数据，以及该属性时间最新的值和上报时间

#### Scenario: 返回尚未上报的定义属性

- **WHEN** 用户查询存在设备，且其 TSL 中定义的属性没有时序上报点
- **THEN** 系统仍返回该属性的 TSL 元数据，并将最后值和最后上报时间设为 `null`

#### Scenario: 按 TSL 属性集合限定结果

- **WHEN** 时序数据包含未在该设备产品 TSL 中定义的键
- **THEN** 系统不得在属性列表中返回该未定义键

#### Scenario: 查询不存在的设备

- **WHEN** 用户查询不存在的设备标识
- **THEN** 系统返回符合既有设备资源约定的未找到错误

### Requirement: 属性页展示物模型定义与当前状态

系统 SHALL 在设备详情的「物模型数据 → 属性」区域展示专用属性最后值查询结果，并以产品 TSL 中的属性顺序呈现属性名称、标识符、当前值、单位、读写方式与最后上报时间。

#### Scenario: 打开属性页

- **WHEN** 用户打开设备详情的属性区域
- **THEN** 前端请求该设备的专用物模型属性最后值接口并展示返回的定义属性

#### Scenario: 属性尚无上报值

- **WHEN** 属性查询结果中最后值为 `null`
- **THEN** 前端展示该属性的定义信息与明确的未上报状态

#### Scenario: 查看属性历史趋势

- **WHEN** 用户选择一个定义属性查看趋势
- **THEN** 前端使用 `/v1/devices/:deviceKey/telemetry/history` 查询该属性的时序数据

#### Scenario: 不使用非属性数据源

- **WHEN** 属性页加载当前值
- **THEN** 前端不得请求设备影子接口或原始最新遥测 JSON 接口
